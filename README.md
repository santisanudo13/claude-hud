# claude-hud

A [Claude Code](https://claude.com/claude-code) mod: a right-docked pane showing

- context window used (tokens and %)
- session spend
- remaining credit and rate-limit usage (5h window, 7d week)
- clickable pending tasks that fill a ready-made prompt

## Install

Inside Claude Code:

```
/plugin marketplace add santisanudo13/claude-hud
/plugin install hud@claude-hud
```

Then restart Claude Code (or run `/reload-plugins`).

If you already have a local copy of `hud` loaded (e.g. from `~/.claude/my-mods/hud`),
disable it first so the two don't clash.

### Manual install

```bash
git clone https://github.com/santisanudo13/claude-hud ~/.claude/my-mods/hud
```

Then load it as a local mod from that folder (`/plugin`) and restart Claude Code.

## Develop

Type definitions in `.claude-plugin/types/` are generated by Claude Code and not
committed. The mod lives in `hooks/register.tsx`.
